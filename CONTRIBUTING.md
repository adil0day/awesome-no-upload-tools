# Contributing

Thanks for helping people find tools that keep their files private.

## Adding a tool

Open a pull request that adds one line to the right section of `README.md`:

```
- [Tool name](https://link) 🟢 ✈️: what it does, in one plain sentence. Any feature that uses a server.
```

- 🟢 only if the source code is public under an open-source licence.
- ✈️ only if the tool keeps working with the internet turned off after the first load.
- Keep entries in a section roughly alphabetical, with no marketing words ("best", "amazing", "#1").

In the pull request description, include:

1. **Proof:** a link to where the tool says files are processed in the browser (README, docs, FAQ or privacy terms).
2. **Exceptions:** any feature that sends your data to a server (exports, AI, cloud saving, lookups).
3. **Your check:** that you tried it with the Network tab open, or offline (see "How to check a tool yourself" in the README).

## What isn't listed

- Tools that upload files for the basic job
- Tools that need an account, payment or a watermark for the basic job
- Self-hosted server apps (great, but a different list)
- Browser extensions that need broad "read all sites" permissions for a simple file job

## Corrections

If a listed tool changes how it handles files, please open an issue with a link. Makers of listed tools are welcome to correct their own entries.
